Almost there: Vercel is showing the code branch

The dashboard lives on the site branch, which GitHub Actions updates every few minutes. This deployment was built from the code branch instead.

  1. Vercel → this project → Settings → Git (in some versions: Settings → Environments → Production).
  2. Set Production Branch to site and save.
  3. Don't use “Redeploy” — it rebuilds this same code-branch version. Instead wait for the next update (a few minutes), or on GitHub open Actions → Collect and publish → Run workflow. A new production deployment from site appears within a minute.

Or open Deployments in Vercel, find one whose branch is site, and choose Promote to Production.
